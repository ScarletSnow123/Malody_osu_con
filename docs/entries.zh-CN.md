# 四个入口与 Node.js 安装

本文档覆盖环境前提，并详细说明四种使用方式。如果只是转一两个包，读主 README 就够了。

## 前提：Node.js

`GUI.bat` / `转换.bat` / `命令行.bat` 都只是外壳，真正的转换由 `core.mjs` 完成。
**`OsuToMalody.html` 不需要任何东西**——转换逻辑整个内联在网页里。

### 会自动找 Node

`gui.ps1` 和 `convert.ps1` 会依次找：

1. 系统 PATH 里的 `node.exe`
2. `C:\Program Files\nodejs\node.exe`
3. `C:\Program Files (x86)\nodejs\node.exe`
4. `%LOCALAPPDATA%\Programs\nodejs\node.exe`
5. 都找不到 → 弹窗提示你去 <https://nodejs.org> 装 LTS 版

想自己确认：开个终端敲 `node -v`，有版本号就行。

## 方式一：图形界面 —— `GUI.bat`（推荐）

### 启动

1. 打开本工具所在文件夹
2. **双击 `GUI.bat`** —— 会**极快地闪一下黑色窗口**（那是启动器），随即弹出应用窗口，
   标题为 `Malody  <->  osu!mania  转换器`
3. 选好文件或文件夹，点 **Start**

那个黑窗是 `GUI.bat` 自己，它只做一件事：用隐藏方式启动 `gui.ps1`，所以不会留下残留的
命令行窗口。

### 界面

```
┌─ Malody  <->  osu!mania  Converter ──────────────────────┐
│  Malody  <->  osu!mania                                  │
│  .mcz → .osz (play in osu!)   .osz/folder → .mcz (edit)  │
│                                                          │
│  Items to convert (you can also drag files in):          │
│  ┌────────────────────────────────────────────────────┐ │
│  │ D:\OSU!\Songs\226766 Sound Piercer ESPITZ...       │ │
│  └────────────────────────────────────────────────────┘ │
│  [Add files…] [Add folder…] [Remove selected] [Clear]    │
│                                                          │
│  ┌ Options ─────────────────────────────────────────┐   │
│  │ Keys [Auto▾]  Time shift (ms) [0]  ☑Compress     │   │
│  │ ☑ Audio sync via Malody offset                   │   │
│  │ Output dir [C:\Users\...\Desktop    ] [Browse…]  │   │
│  │              Output style [Full▾]                │   │
│  └──────────────────────────────────────────────────┘   │
│                                                          │
│  [ Start ]  [Open output folder]        Ready            │
│  Log:                                                    │
│  ┌────────────────────────────────────────────────────┐ │
│  │ [1/2] D:\OSU!\Songs\...                            │ │
│  │     √ generated xxx.mcz  (1.85 MB)                 │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

### 操作步骤

1. **添加要转换的东西**（以下任选）：
   - 点 **Add files…** → 原生文件框，多选，过滤 `.mcz / .osz / .zip / .osu`
   - 点 **Add folder…** → 原生文件夹框
   - 或**直接把文件/文件夹拖进列表**（可一次拖多个）
2. **确认输出目录**（默认桌面），点「Browse…」可改
3. **按需调选项** —— 默认值一般够用，见下表
4. 点 **Start**
5. 看**日志**：每个产物一行，`√ generated xxx.mcz (1.85 MB)`
6. 完成后点「打开输出目录」

### 选项含义

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 键数 | 自动 | 很少需要手动设；只在谱面键数识别错了时改（4K–10K） |
| 时间微调 (ms) | 0 | 成品整体偏早/偏晚时用，正数=整体延后 |
| 压缩输出 | 开 | 关掉兼容性最好但体积更大 |
| 按 Malody offset 换算音画同步 | 开 | 音画对齐的关键开关（见 [格式规则](format-spec.zh-CN.md)）。若成品整体偏移就取消勾选 |
| 输出格式 | 完整 | 「精简」是备用形态，两个 Malody 版本实测都用「完整」（见 [版本兼容](compatibility.zh-CN.md)） |
| 输出目录 | 桌面 | 产物放哪 |

### 关于输出位置

- 单个谱面集（一个 osu! 歌曲文件夹）→ 直接输出到桌面，如 `某曲名.mcz`
- 含多个包的文件夹 → 会在输出目录下**建一个同名子文件夹**，产物集中放进去
- 日志里会列全路径

### 如果窗口没出现

- 先等 1～2 秒（PowerShell 启动 + WinForms 初始化需要一点时间）
- 若始终没有：多半是**杀毒软件拦了 PowerShell 脚本**，把本文件夹加白名单，或改用
  `OsuToMalody.html`

## 方式二：拖放 —— `转换.bat`（步骤最少）

### 启动

**方式 A（拖放，推荐）**

1. 选中一个或多个文件/文件夹
2. 拖到 `转换.bat` 的图标上，松手
3. 会弹出一个**黑色命令行窗口**，显示转换进度

**方式 B（双击）**

1. **双击 `转换.bat`**（不带任何东西）
2. 弹出**文件夹选择框** → 选一个目录
3. 转换开始

### 运行过程与结束

窗口里会依次显示：找到的 Node 运行时、输出目录、每个文件的转换详情、最后是结果汇总：

```
  已生成  xxx.mcz   (1.85 MB)
完成：共生成 1 个文件。
  .mcz 拖进 Malody 即可导入编辑；.osz 拖进 osu! 窗口即可导入。

按回车打开输出目录（输入 n 直接退出）
```

按**回车** → 资源管理器自动打开并选中产物；输入 `n` → 直接退出。

### 支持的输入（可一次拖多个）

| 拖进去 | 得到 |
| --- | --- |
| `.mcz`（Malody 谱面包） | `.osz` |
| `.osz` / `.zip`（osu! 谱面包） | `.mcz`（混键数会拆成 `_4K.mcz` / `_7K.mcz`） |
| `.osu`（单个谱面） | `.mc`（注意：不含音频/背景） |
| **含 `.osu` 的文件夹**（osu! 歌曲文件夹） | `.mcz` |
| **含 `.mcz` 的文件夹** | 每个转成 `.osz`，集中放进一个子文件夹 |

### 输出位置

默认**桌面**。想换：先设环境变量 `MALODY2OSU_OUT` 再运行，例如在终端里：

```cmd
set MALODY2OSU_OUT=D:\转换输出
```

### 和 GUI 的区别

拖放**不问任何选项**，全部用默认值。要调选项就用 `GUI.bat` 或命令行。

## 方式三：命令行 —— `命令行.bat`

### 启动

**双击 `命令行.bat`** → 打开一个终端窗口，**工作目录已经自动切到本工具文件夹**，
并打印用法说明。

也可以自己开终端 `cd` 过来。

### 用法

```bash
node cli.mjs <输入> [-o 输出] [选项]
```

> ⚠️ **路径务必用双引号包起来。** 路径含空格、`&` 等在 cmd 里有特殊含义的字符时，
> 不加引号会被截断。

### 输入可以是

| 输入 | 输出 |
| --- | --- |
| `.mcz` | `.osz` |
| `.osz` / `.zip` | `.mcz` |
| `.osu` | `.mc` |
| 含 `.osu` 的目录 | `.mcz`（混键数自动拆包） |
| 其它目录 | 目录里的每个 `.mcz` / `.osz` / `.zip` / `.osu` 逐个转换，**两个方向都支持** |

### 选项

| 选项 | 说明 |
| --- | --- |
| `-o, --output` | 输出路径（目录输入时作为输出目录） |
| `--key N` | 强制键数（默认读取谱面） |
| `--shift MS` | 整体时间微调，正数=延后 |
| `--denom N` | Malody 拍分母（默认 288） |
| `--no-sync` | 不做同步换算（成品整体偏移时用） |
| `--mc-style full\|minimal` | 输出格式风格，默认 `full`（见 [版本兼容](compatibility.zh-CN.md)） |
| `--no-compress` | 关闭压缩 |
| `-r, --recursive` | 递归子目录，可一次转完整个 `D:\OSU!\Songs` |

### 例子

```bash
:: 单个 osu! 歌曲文件夹 → .mcz
node cli.mjs "D:\osu!\Songs\某曲目" -o "输出.mcz"

:: Malody 谱面包 → .osz
node cli.mjs "某谱面包.mcz" -o "输出.osz"

:: 批量：整个 osu! 曲库 → 全部转成 .mcz，产物集中到 D:\转换输出
node cli.mjs "D:\osu!\Songs" -r -o "D:\转换输出"

:: 一个装满 .mcz 的文件夹 → 每个都转成 .osz
node cli.mjs "D:\Malody谱包" -o "D:\转出来的osz"
```

## 方式四：网页应用 —— `OsuToMalody.html`（备用，非推荐）

> [!IMPORTANT]
> **这是备用入口，不是推荐做法。** 日常转换请用 [`GUI.bat`](#方式一图形界面--guibat推荐)，
> 拖放用 [`转换.bat`](#方式二拖放--转换bat步骤最少)，批量／整个曲库用
> [`命令行.bat`](#方式三命令行--命令行bat)。网页版只在「换了台电脑、不想装 Node.js、
> 手头只有一两个包」这种情况下才值得用：
>
> - **按「一个包 = 一首歌」处理，没有批量与递归**。整个 osu! 曲库（如 `D:\osu!\Songs`）
>   请用命令行版：网页版用「选择文件夹」选到含多首 `.osu` 的目录时，这些谱面会被**并进
>   同一个 `.mcz`**，而不是逐首转换。
> - **所有数据都在浏览器标签页的内存里处理**。整包读进页面、产物也在页面里生成，包一大
>   就容易卡顿，甚至被浏览器掐掉（桌面版／命令行没有这个上限）。
> - **产物位置不可控**。只能落到浏览器的下载目录，不能指定输出目录；一次转换多个包时，
>   浏览器还可能弹「是否允许此网站下载多个文件」。
> - **不能脚本化**。没有递归、批量和 `-o` 这类参数。

### 启动

**双击 `OsuToMalody.html`** → 用系统默认浏览器打开。

**这个入口不需要 Node.js，也不依赖同目录的其它任何文件**——它把整个转换核心内联进了
HTML，可以单独拷到 U 盘、别的电脑、发给别人用。完全离线，不上传任何文件。

### 操作步骤

1. 把 `.mcz` / `.osz` / `.zip` **拖进虚线框**，或点「选择文件」（支持多选）
2. 或者点「**选择文件夹**」，选一个 osu! 歌曲目录（如 `D:\OSU!\Songs\某曲目`）
3. 在页面上按需改选项（键数／时间微调／压缩／同步换算）
4. 处理完**自动下载**，页面下方会列出每个结果的详情和下载按钮

### 和桌面版的区别

| | 桌面版（GUI.bat） | 网页版 |
| --- | --- | --- |
| 需要 Node.js | 需要 | **不需要** |
| 批量／整个曲库 | 支持（命令行可递归） | **不支持**（多首会并成一个包） |
| 大包处理 | 落盘处理，基本不受限 | 全在标签页内存里，包大易卡／失败 |
| 输出位置 | 桌面（可选） | **浏览器的下载目录**（由浏览器设置决定） |
| 文件夹选择 | 原生文件夹框 | 浏览器文件夹选择器 |
| 多包下载 | 逐个落盘，无提示 | 浏览器可能弹「允许多文件下载」 |
